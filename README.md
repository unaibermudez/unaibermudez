## Projects

**[TripMap](https://github.com/unaibermudez/TripMap)** · [live demo](https://unaibermudez.github.io/TripMap/)
Interactive map and timeline to tell the story of a trip. Astro, React, MapLibre and Zustand, with a Zod-validated data model, 155 unit tests and visual regression tests with Playwright.

**[Stockle](https://github.com/unaibermudez/stockle)**
Daily Wordle-style game for guessing stocks. Vanilla JavaScript, no build step and no dependencies. Prices are refreshed by a scheduled GitHub Action.

**[Commit Drawings](https://github.com/unaibermudez/github-commit-drawingsV2)**
Draw a pattern on the GitHub contribution grid and export a Bash or PowerShell script that recreates it using `git fast-import`. React, TypeScript, Vite and Tailwind.

**[Portfolio & blog](https://github.com/unaibermudez/unaibermudez.github.io)**
Bilingual personal site built with Astro. One URL serves both Spanish and English, with generated OG images and full-text search.
